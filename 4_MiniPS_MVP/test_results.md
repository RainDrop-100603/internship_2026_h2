### 진행 원칙

- 입력값의 `코드`는 그대로 붙여 넣는다. 값 도움말(칸 오른쪽 아이콘)로 골라도 된다.
- **날짜**는 달력 아이콘으로 고르는 게 가장 확실하다. 직접 칠 때는 화면 형식(예: `Mar 1, 2026`)에 맞춘다. 아래 표에는 `2026-03-01`처럼 적었다.
- 오류는 **Save(저장) 시점**에 표시된다 (draft 방식). 해당 칸 빨간 표시 + 하단 메시지 아이콘 확인.
- 일부 차단은 메시지 대신 **입력칸 회색 / 버튼 숨김**으로 나타난다 → 차단되면 통과.
- 오류 시나리오는 확인 후 **Discard(취소)** 해서 draft가 남지 않게 한다.
- 시나리오마다 결과·메시지를 적고 캡처 1장 (`captures/1-4.png`처럼 단계 번호로 이름).
- 데이터가 꼬이면 `ZCL_PS_SEED_TESTDATA_YJ`를 다시 실행 (`T` 데이터만 원상복구, 직접 만든 데이터는 유지).
- 아래 "적지 않은 칸"은 비워 둔다.

결과 표기: ✅ 통과 · ❌ 실패 · ⚠️ 부분 통과/확인 필요 · ➖ 해당 없음
