# 로컬 서버 보안 기본값

콘솔 백엔드는 Claude/Codex를 대신 실행하고 git 작업(merge, worktree 삭제 등)을 수행하므로,
로컬 전용 도구라 해도 아래 기본값을 Phase 2 백엔드 구현 시점부터 지킨다.

- **바인딩**: `127.0.0.1`에만 바인딩한다. `0.0.0.0`이나 외부 인터페이스에 노출하지 않는다.
- **인증 토큰**: 서버 시작 시 nonce 토큰을 발급하고, 프런트(브라우저)는 이 토큰을 모든 API 요청에 포함한다. 토큰은 프로세스 재시작마다 갱신한다.
- **CORS 차단**: 브라우저의 다른 출처(origin)에서의 요청을 차단한다. 프런트 dev 서버 origin만 필요 시 명시적으로 허용한다.
- **destructive API 재확인**: worktree 삭제, git merge/cherry-pick, 프로세스 kill 등 되돌리기 어려운 동작은 프런트에서 명시적 확인 없이 실행되지 않도록 한다. 백엔드는 토큰과 `confirm: true`, URL과 일치하는 `taskId`를 요구한다. 승인/반려는 화면에 표시된 `targetSha`와 `diffHash`까지 일치해야 실행한다.

이 문서는 원칙 체크리스트이며, 실제 서버 코드는 Phase 2에서 구현한다.
